② 训练超参数

P2RLoss（CVPR 2025 半监督点预测）：教师-学生 EMA + Point-to-Region 损失。 默认超参对齐论文（Adam 5e-5 / 骨干 1e-5 + 恒定学习率 + P2R 损失）， 界面可调整优化器/学习率/调度器，损失默认 P2R 并支持追加自定义附加损失（契约 aux(pred_density, target_seq)）。 「有标注样本比例」<1 时仅该比例图像带标注，其余作为无标注数据参与伪标签训练（种子确定性划分）； 标注格式支持 .txt（每行 x y）/ .mat / .npy（(N,2) 坐标，P2RLoss 源格式）。

Consistent-Point（arXiv 2503.12441 半监督点预测）：P2PNet 基座 + PA 位置聚合 + IUC 不确定性校准 + Mean-Teacher。 默认超参对齐论文（Adam 1e-4 / 骨干 1e-5 + 恒定学习率 + P2PNet 损失，λ_u=0.1 / K=4 / EMA 0.999）， 界面可调整优化器/学习率/调度器，损失默认 Consistent-Point 并支持追加自定义附加损失。 「有标注样本比例」<1 时仅该比例图像带标注，其余作为无标注数据参与伪标签训练（种子确定性划分）； 标注格式支持 .txt（每行 x y）/ .mat / .npy（(N,2) 坐标）。

CU（ICCV 2023 半监督点预测）：P2PNet 基座 + patch 级不确定性分支 + PatchBank ASM 代理真值 + 排序损失 + 课程伪标签过滤 + Mean-Teacher。 默认超参对齐论文（Adam 1e-4 / 骨干 1e-5 + 恒定学习率 + P2PNet 损失，λ₁=0.3 / patch=64 / u_max=0.5 / EMA 0.999）， 界面可调整优化器/学习率/调度器，损失默认 CU 并支持追加自定义附加损失。 「有标注样本比例」<1 时仅该比例图像带标注，其余作为无标注数据参与伪标签训练（种子确定性划分）； 标注格式支持 .txt（每行 x y）/ .mat / .npy（(N,2) 坐标）。

YOLO 系列（ultralytics 引擎）：优化器 / 调度器 / 损失由引擎托管， 以下增强参数与「数据增强」开关生效（增强强度整体缩放）。

知识蒸馏：以大模型（教师）的中间特征为软目标训练小模型（学生）， 在参数量更少的情况下保持性能。教师优先选同数据集训练产物（类别一致）； 官方 COCO 教师亦可（特征与得分加权与类别数无关，引擎投影层自动对齐通道差异）。 师生需同为 3 尺度 Detect 头的 YOLO 系列（RT-DETR / YOLOv6 暂不支持）。

③ 数据集

密度图路线数据集：根目录含 Train/Test 子目录，各含 Images/（图像）与 GT/（*.npy 密度图 或 *.txt 点标注，每行 "x y"）；.mat 点标注请先用下方工具 转换为 .npy；兼容 imgs/ + gt/npys/ 扁平结构。上传 zip 后自动解压。

单域泛化在源域训练、目标域测试；目标集仅用于每轮跨域 MAE 评估与最优模型选择，不参与训练。
